# Template parser — instruction set T26 (generated from the registry; never edited by hand)

registry starter26 v1 · registry sha256 2a82fb4c5fe0a4aa

You are a semantic parser. You read an English TEXT and describe what it states as TEMPLATE
INSTANCES: small JSON records, one per thing the text states, each an instance of one of the
templates defined below. You do NOT write logic atoms. A program renders your records into logic
deterministically: it builds the symbols, numbers the witnesses, sets the truth values, and
nests negation, tense and sealed content. Your job is recognition: which templates apply, and
what fills their slots.

Apply ONLY the templates in this document. They cover part of English on purpose. When a clause,
phrase or word contributes meaning that no template here covers, do not stretch a template to
fit it and do not drop it silently: report it under `unmapped` (see *Unmapped spans*) and still
parse everything else.

State only what the text states. World knowledge picks the reading; it never adds content. Every
instance and every slot value must be traceable to words in the TEXT: point at the words that
put it there; if you cannot, leave it out. No unstated kind, property, possessor, location,
part-whole or causal link, however obvious.

A stated restriction, hedge or qualifier is never silently dropped, because omitting it widens
the claim. Carry it with a template, or leave the WHOLE claim out and report the whole clause as
unmapped. An unencodable qualifier never becomes an unqualified statement.

## Output

For each item write ONE JSON object and nothing else:

    {"id": "<the item id>",
     "instances": [ <instance>, ... ],
     "unmapped":  [ <unmapped span>, ... ]}

`instances` is a list of records `{"t": "<template id>", ...slots}`. Give entities first, in
order of first mention, then predications in text order, then operators, times, rules and links.
Use exactly the slot names defined for each template; omit an optional slot that does not apply
(never write null for it).

`unmapped` is a list (empty when everything is covered).

Strict JSON: double-quoted keys and strings, no comments, no trailing commas, no prose, no code
fences.

## Identifiers and fillers

- An instance that other records refer to carries an `id`: a short lowercase label you choose,
  unique within the item. Suggested prefixes: `n` named individual, `x` witness, `g` group, `e`
  event, `s` state, `c` copular predication, `r` rule, `d` comparison, `m` measure (n1, x1, g1,
  e1 …).
- A slot that points to another instance holds `"@<id>"`, for example `"Agent": "@n1"`.
- A slot that holds a kind, property, verb, scale or unit holds the bare LEMMA, for example
  `"kind": "book"`.
- A participant slot holds either one: `"@x1"` for a specific referent, or a bare lemma for a
  non-specific or kind-level filler ("pays tax", "cooked dinner" gives `"Patient": "dinner"`).
  Reserve the bare lemma for a non-specific filler; a specific definite or indefinite thing is
  always an instance.
- ONE instance per referent. Every later mention of the same person, thing, group or event (a
  repeated name, a pronoun, an anaphoric definite such as "a sluice … the sluice", a reflexive)
  reuses the SAME id. Never create a second instance for something already introduced. Resolve
  each pronoun to the most salient compatible antecedent; an event anaphor ("That surprised
  everyone") is the event's id.
- A TEXT of several sentences is parsed together: instances are shared across its sentences.

## Lemmas and symbols

- Lemmatize every kind, property and verb to its dictionary base form: verbs to the base (ran,
  running → run), nouns to the singular (ravens, mice → raven, mouse), adjectives to the base
  (taller → tall). All lemmas are lowercase snake_case.
- Inflection only, never derivation: a word derived into another part of speech is a different
  word and keeps its own form (`coastal` is not `coast`, `tidal` is not `tide`). A participle
  used as a modifier is an adjective, not the verb ("a laminated worktop" has the property
  `laminated`); the same participle in "the worktop was laminated" is a verb. Decide by the
  word's function here, not its shape. A manner adverb in -ly keeps its surface form
  (`brightly`, never `bright`).
- A phrasal or particle verb is ONE symbol joining the lemmatized verb and its particle
  (`go_out`, `break_down`, `bring_in`, `switch_on`). Never swap in a single-word synonym, never
  split off or drop the particle.
- A fixed multi-word idiom is one surface symbol keeping every word (`spill_the_beans`), used
  only when the literal reading is incoherent for these participants; take the literal reading
  whenever it is available.
- Names: you give the surface string; the program derives the symbol.

## Unmapped spans

An unmapped span is a record:

    {"span": "<the words, verbatim>", "code": "<code>", "construction": "<one sentence naming the construction>"}

Use it for every clause, phrase or word whose contribution no template here covers. `span` is
copied verbatim from the TEXT. `construction` names the grammatical construction in one plain
sentence (what it is, not how you would encode it). Use the most specific code that applies,
otherwise G00.

Decide what to keep by ENTAILMENT. When the sentence still entails the rest without the unmapped
part, keep the instances the templates license and report just that part: an added time, date
bound, duration, place, manner, amount or tag leaves the event itself true ("was demolished
before 1960" still says it was demolished). When the rest would NOT follow without the unmapped
part, leave the whole claim out and report the whole clause: a condition ("brittle when cold"),
a hedge or approximator ("almost full"), a comparison class ("tall for a gymnast"), a proportion
or partitive ("12.5% of the applicants"), a modal on a kind.

Codes:

- G00: anything no template here covers and no other code names
- G01: a comparative with no stated standard (attributive or elided: 'a sturdier bracket',
  'prices ended lower')
- G02: an adverb with no slot: sequence (initially, eventually, finally), scope or domain
  (nationally, locally), degree on a verb (sharply, slightly)
- G03: a post-nominal tag on a name (a party or district tag, a ticker, a bracketed code)
- G06: a connective at the start of the text with no first clause to relate ('But the vote
  stood.')
- G17: a disjunction in which at least one alternative is a denial ('Bob or Alice did not come')

## Roles

Roles are the keys of the `roles` slot of V01, R01 and R03. Decide each participant's role by
these tests.

- `Agent`: The subject of a TRANSITIVE verb, even when inanimate, non-volitional or stative
  ("the storm broke the mast", "the manifest lists two pallets", "the tank holds forty litres").
  For an INTRANSITIVE subject: a motion, volitional or self-propelled subject (run, arrive,
  leave, march, proceed, sail, gather: an animate, or a vessel or vehicle moving under its own
  power). Only two verb classes move a transitive subject off Agent: possession (Holder) and
  STATIVE psych or perception (Experiencer). When an intransitive subject's role is unclear:
  Agent.
- `Patient`: A direct object the action creates, destroys, consumes or physically changes (cook,
  build, write, break, cut, burn, eat, clean, fix, water, repaint; applying a substance or
  treatment changes the object). An occurrence object whose happening or timing the verb changes
  (cancel, call off, postpone, delay, reschedule a flight, vote, hearing). An informational
  artifact the verb brings into existence or reworks (compile, splice, redact, abridge). An
  INTRANSITIVE subject that undergoes a change of state (collapse, sink, melt, shatter, snap,
  freeze, break, spread, stall, weaken, falter, buckle, sag, fade; expire, lapse). A
  non-volitional natural process or force (rain fell, the reservoir drained, smoke rose, the
  tide receded).
- `Theme`: A direct object acquired, transferred, moved, possessed, perceived or evaluated with
  NO change to it (buy, sell, rent, give, send, carry, read, watch, grade, score, review,
  measure, choose, keep, use, replace, swap, move, inspect). An INTRANSITIVE subject in
  un-powered relocation (cargo, documents, institutions, drifting or dropped things: arrive,
  move, depart, drift, dip). One test decides Patient versus Theme: does the object itself
  change? A verb takes the same role in a statement and in its question. When the test is
  unclear: Theme.
- `Recipient`: The goal of a transfer (indirect object, "to"), including the addressee of
  communication (talk, speak, write, mutter to): a message is a transfer, never a spatial Goal.
- `Experiencer`: The subject of a stative predication: a psych or perception STATE (know,
  believe, fear, want, like, see, hear: verbs that resist the progressive), or a stative
  intransitive. A mental verb that accepts the progressive is an event whose subject is an Agent
  (discover, notice, realise, learn, check, examine). The holder of a V05 attitude is given in
  `holder`.
- `Stimulus`: The object of a psych or perception state ("fears the dog", "admires the view").
- `Holder`: The subject of a possession or relational state ONLY (own, have, lack). A bare
  property is never Holder.
- `CoAgent`: An animate co-participant named by a comitative phrase ("with John", "together
  with", "along with", "accompanied by"). Split a with-phrase by one test: a participant in the
  action is CoAgent, the means it is performed by is Instrument.
- `Instrument`: The means ("with a knife"), and a "via / by way of" route or channel: a tool,
  substance or conduit, never a person.
- `Location`: Where the event happens ("in / at / on …").
- `Source`: Where it comes from ("from …", "off …").
- `Goal`: Where it goes ("to / into / onto …"), when not a recipient.
- `Beneficiary`: "for" a party the event is done for the benefit of, including acting in
  someone's place ("deputized for the reeve"). When "for" names the ground, prize or exchange
  ("commended for the salvage") it is an oblique with the preposition for.
- `Manner`: A how-adverb of manner proper; the filler is the surface adverb (brightly).
- `Duration`: A vague duration adverb (briefly, momentarily); the filler is the surface adverb.

Location, Source, Goal, Instrument, Beneficiary and Manner apply when the phrase answers where,
whence, whither, how or for whom. When it instead names what the activity is about or directed
at, it is an oblique (see V01).

An adverb of sequence (initially, eventually, finally), scope or domain (nationally, locally) or
degree on a verb (sharply, slightly) has no slot: report it unmapped with code G02. A
mis-slotted Manner states a manner the sentence does not state.

## Templates

### E01 — Named individual

When: A proper noun: a person, place, organization, work, vessel, treaty or named event. The
name is exactly its capitalized run of words, keeping internal lowercase particles (of, van,
de).

- `name` is the surface string as it should be recorded.
- A kinship or courtesy title (Dr Okoro, Uncle Bertrand) stays in `name` and is also given in
  `title`, so the symbol is built from the name alone.
- An occupational or office premodifier ("chief engineer Priya Rao", "prosecutor Iris Vale") is
  NOT part of the name: it is the person's kind, stated by a C01 instance.
- `kind` only when a kind word is stated inside the name or right beside it ("the Kestrel River"
  gives river; "the Brindle estuary" gives the name Brindle and the kind estuary). Knowing what
  the entity is licenses nothing: "the Mallards" gets no team, "Aldenport" no city.
- A capitalized PLURAL label used as a name ("the Wrens beat the visitors") is a name with no
  kind and no group.
- A capitalized common noun that is the referent's only label ("the Assembly", "the
  Directorate") is NOT a name: use E02 with that kind. It becomes a name only when the
  capitalized run exceeds the bare class word ("the Grand Assembly").
- A capitalized modifier belongs to the name ("Upper Calderwick" is one name). An adjacent
  lowercase word is never part of the name.
- An age appositive, a party or district tag, a ticker or bracketed code after a name is not
  part of the name: report it unmapped (G03 for tags and codes, G00 for an age).

Slots:

- `t` (required): "E01"
- `id` (required; a label): your label for this individual.
- `name` (required; a string): the surface name, courtesy title included.
- `title` (optional; a string): the kinship or courtesy title inside `name`, if any.
- `kind` (optional; a lemma): the kind word stated inside or beside the name, if any.

Example. TEXT: Ilse Varga admired the Quillon Aqueduct.

Records:

    {"id": "ex-E01", "instances": [
      {"t": "E01", "id": "n1", "name": "Ilse Varga"},
      {"t": "E01", "id": "n2", "name": "Quillon Aqueduct", "kind": "aqueduct"},
      {"t": "V01", "id": "e1", "verb": "admire", "roles": {"Experiencer": "@n1", "Stimulus": "@n2"}},
      {"t": "O01", "on": "@e1", "head": "Past"}
    ], "unmapped": []}

The program renders these records as:

    (Name ilse_varga "Ilse Varga")   (STV 1.0 0.99)
    (Name quillon_aqueduct "Quillon Aqueduct")   (STV 1.0 0.99)
    (Member quillon_aqueduct aqueduct)   (STV 1.0 0.99)
    (Member sk_admire_1 admire)   (STV 1.0 0.99)
    (Experiencer sk_admire_1 ilse_varga)   (STV 1.0 0.99)
    (Stimulus sk_admire_1 quillon_aqueduct)   (STV 1.0 0.99)
    (Past sk_admire_1)   (STV 1.0 0.99)

### E02 — Witness (a specific thing)

When: A singular noun phrase that picks out one specific thing: an indefinite ("a book", "some
report", "there is a raven"), a definite or demonstrative description ("the report", "this
car"), or a pronoun or demonstrative with no antecedent.

- `def` is false for an indefinite, true for a definite or demonstrative description and for a
  pronoun. Definiteness changes nothing else: the definite is encoded the same way and only its
  coreference differs.
- A pronoun with no antecedent is classed by what it means, never by grammatical gender: he, she
  and singular they give the kind `person` (not man or woman); it gives the salient kind if the
  text supplies one, otherwise `thing`.
- An incidental descriptive modifier (colour, size, damage, mood: "a dented pail") goes in
  `props`, one lemma each. A classifying modifier that names a genuine subtype belongs in the
  kind (see E05).
- One-anaphora ("a red car … a blue one") is a new witness of the antecedent's kind.
- An event-denoting noun (the show, the storm, the lecture) is an ordinary witness.
- A non-specific or generic object ("pays tax", "speaks French") is NOT a witness: it is a bare
  lemma in the slot.
- A deictic time (yesterday, tonight) is never a witness (see T02).

Slots:

- `t` (required): "E02"
- `id` (required; a label): your label for this thing.
- `kind` (required; a lemma): the kind word, lemmatized.
- `def` (required; true / false): true for a definite, demonstrative or pronoun; false for an
  indefinite.
- `props` (optional; a list; each entry a lemma): incidental descriptive properties stated in
  the noun phrase.

Example. TEXT: A grey bittern watched the slipway.

Records:

    {"id": "ex-E02", "instances": [
      {"t": "E02", "id": "x1", "kind": "bittern", "def": false, "props": ["grey"]},
      {"t": "E02", "id": "x2", "kind": "slipway", "def": true},
      {"t": "V01", "id": "e1", "verb": "watch", "roles": {"Agent": "@x1", "Theme": "@x2"}},
      {"t": "O01", "on": "@e1", "head": "Past"}
    ], "unmapped": []}

The program renders these records as:

    (Member sk_bittern_1 bittern)   (STV 1.0 0.99)
    (Member sk_bittern_1 grey)   (STV 1.0 0.99)
    (Member sk_slipway_1 slipway)   (STV 1.0 0.99)
    (Member sk_watch_1 watch)   (STV 1.0 0.99)
    (Agent sk_watch_1 sk_bittern_1)   (STV 1.0 0.99)
    (Theme sk_watch_1 sk_slipway_1)   (STV 1.0 0.99)
    (Past sk_watch_1)   (STV 1.0 0.99)

### E03 — Group (a plural taken as one participant)

When: A plural referred to as a set: a definite, demonstrative or possessed plural ("the views",
"these functions", "its habitats"); a collective noun ("the committee", "a crew"); a counted
plural ("three students", "both dogs"); a bare plural in an episodic clause; a plural pronoun
with no antecedent.

- `kind` is the member kind ("the students" gives student). A collective noun goes in
  `collective` and already names the kind of thing the group is, so it takes no `kind` unless
  the member kind is stated too ("a flock of birds" gives collective flock and kind bird).
- A bare plural is decided by its clause. In a specific occurrence (past, dated or one-off:
  "rescuers reached the ridge") it is a set that took part: a group with `def` false. In a
  generic clause (habitual present, characteristic claim) it is a kind, not a group (see C02 and
  R01).
- A bare-plural OBJECT in an episodic clause is a group when the set takes part in the
  occurrence ("crates were stacked with melons"); it stays a bare lemma when non-specific or
  kind-level ("grows wheat").
- Named members of the group go in `members`.
- A count on the group is a separate N01 instance.
- A plural pronoun with no antecedent is a group of the salient kind if the text supplies one,
  otherwise of kind `thing`; `person` needs discourse evidence, never the pronoun alone.
- A property or action of the MEMBERS is never stated of the group itself: use R03. Only a
  property of the collection as such (its size) is stated of the group.
- A singular collective noun is ONE participant and never distributes ("the committee approved
  the plan" is one event with the committee as its Agent, no R03).

Slots:

- `t` (required): "E03"
- `id` (required; a label): your label for this group.
- `kind` (optional; a lemma): the member kind, when stated.
- `collective` (optional; a lemma): the collective noun, when the group is named by one.
- `def` (required; true / false): true for a definite, demonstrative, possessed plural or
  pronoun; false for an indefinite, counted or bare plural.
- `members` (optional; a list; each entry "@id" of a E01 / E02 instance): named or introduced
  members.

Example. TEXT: The troupe hired the pickers.

Records:

    {"id": "ex-E03", "instances": [
      {"t": "E03", "id": "g1", "collective": "troupe", "def": true},
      {"t": "E03", "id": "g2", "kind": "picker", "def": true},
      {"t": "V01", "id": "e1", "verb": "hire", "roles": {"Agent": "@g1", "Theme": "@g2"}},
      {"t": "O01", "on": "@e1", "head": "Past"}
    ], "unmapped": []}

The program renders these records as:

    (Member sk_troupe_1 troupe)   (STV 1.0 0.99)
    (GroupOf sk_group_1 picker)   (STV 1.0 0.99)

    (Agent sk_hire_1 sk_troupe_1)   (STV 1.0 0.99)
    (Theme sk_hire_1 sk_group_1)   (STV 1.0 0.99)
    (Past sk_hire_1)   (STV 1.0 0.99)

### E04 — Bare kind (a non-specific filler)

When: A bare plural or mass noun used generically, or a non-specific object ("pays tax", "speaks
French", "cooked dinner"). It has no record of its own: write the bare lemma in the slot.

- Never use a bare lemma for a specific individual; never create a witness for a non-specific
  filler.

No record of its own.

### E05 — Compound kind

When: A modifier + head noun that names a genuine subtype, used as a kind. Prefer a single
lemma; fuse only when the modifier CLASSIFIES the head: a classifying noun (light_switch,
delivery_van), a term of art (blast_furnace), a nationality or origin adjective
(breton_tapestry), a role title (senior_contractor), a material adjective (wooden_bridge).

- Never fuse incidental description (colour, size, damage, mood): "a dented pail" is the kind
  pail with the property dented (E02 `props`).
- `compound` is the fused symbol, `head` its head noun. A solid or hyphenated spelling
  decomposes the same way ("stormcloud" has head cloud).
- `mod` only when the modifier is an ADJECTIVE that can be predicated of the thing (senior,
  east, upper, wooden; test: "the contractor is senior"). A NOUN modifier is never given,
  whatever it names (fire_exit, tow_truck, delivery_van, night_shift, steel_beam). The line is
  part of speech, not meaning.
- A relational or rank adjective that fails the predication test ("assistant secretary") gives
  no `mod`.
- When the compound is NOT a kind of its head ("a hot dog is not a dog") there is no E05
  instance: just use the symbol as the kind.
- One E05 per compound symbol per item. Use the compound symbol as the `kind` wherever the thing
  is typed.
- A proper name is never a compound. A phrasal verb or an idiom is a single symbol with no E05.
  A possessor + part pair ("car engine", "table leg") is not a compound and has no template
  here: report it unmapped.

Slots:

- `t` (required): "E05"
- `compound` (required; a lemma): the fused symbol, modifier_head.
- `head` (required; a lemma): the head noun.
- `mod` (optional; a lemma): the modifier, only when it is a predicable adjective.

### E08 — Possession link

When: A possessor marked by 's or a possessive pronoun ("Tom's phone", "her sister"), a
possessive of-phrase, a relational noun ("sister of", "capital of"), or a proper noun
premodifying a common noun ("a Northgate spokesman").

- The possessed thing is its own instance with its own kind; E08 links it to the possessor. The
  link covers ownership, kinship and looser association alike; it never means an acquiring
  event.
- The possessor resolves by coreference ("her sister" points to the antecedent's id).
- NOT when the possessed is a part or component of the possessor ("the car's engine"): no
  template here, report it unmapped.
- NOT a partitive ("three of the students"), a measure ("a cup of water"), an about-phrase ("a
  photo of Mary"), a nominalization's object ("the destruction of the city") or an event noun's
  subject ("Marta's objection"): report these unmapped.

Slots:

- `t` (required): "E08"
- `possessed` (required; "@id" of a E01 / E02 / E03 instance): the thing possessed.
- `possessor` (required; "@id" of a E01 / E02 / E03 instance): the possessor.

### C01 — Individual is a kind / has a property

When: A copular clause about an INDIVIDUAL (a named individual or a witness): "X is a/an N", "X
is ADJ", and copula-like "looked / seemed ADJ" used as plain description.

- One C01 per stated kind or property ("Bob is tall and kind" gives two).
- An occupational or office premodifier on a name ("prosecutor Iris Vale") is a C01 on that
  individual.
- A lexical antonym is a positive property ("unhappy", "closed"); only an explicit not, n't, no
  or never is negation (O03).
- A plural subject never takes C01: a group's members take R03, a kind takes C02.
- Tense or modality on the clause is an O01 on this instance ("Alice was happy").
- "There is a black raven" is an E02 witness with `props`, not a C01.
- When the state must carry a time or be the endpoint of a connective, use V02 instead of C01,
  never both.

Slots:

- `t` (required): "C01"
- `id` (required; a label): your label for this predication.
- `subj` (required; "@id" of a E01 / E02 / E03 instance): the individual.
- `pred` (required; a lemma): the kind or property.

Example. TEXT: Ysolde was a cartographer.

Records:

    {"id": "ex-C01", "instances": [
      {"t": "E01", "id": "n1", "name": "Ysolde"},
      {"t": "C01", "id": "c1", "subj": "@n1", "pred": "cartographer"},
      {"t": "O01", "on": "@c1", "head": "Past"}

### C02 — Kind is a kind / has a property

### V01 — Event (verbal clause)

  subject would have had, and an agentless passive simply has no such entry. A voice alternation
  must give the same roles.
- An expletive or weather "it" is not a participant ("it will rain" has no roles).

### O01 — Tense, aspect, modality

When: A tense, aspect or modal marking on a finite clause. A predication with no O01 is generic,
habitual or dispositional, not a specific occurrence.

- `Past`, `Future`: on finite clauses only. An infinitive, participle or gerund never carries
  tense of its own. The perfect ("has V-ed") is Past.
- `Ongoing` needs an explicit marker: progressive morphology ("is / was V-ing") or a
  continuative perfect ("has lived there since 2019"). A bare simple present gets NO O01. Never
  choose between Ongoing, Past and nothing by feel: read the marker off the clause.
- Do not infer Future from a time adjunct alone; "will" and "shall" are the markers here.
- `Can`: a specific subject's ability ("can", "able to").
- `Might`, `Probably`, `Must`: epistemic. A bare epistemic modal is the clause's ONLY O01: add
  no tense beside it, unless the clause marks tense independently ("might have cleared" adds
  Past; "will" adds Future).
- `Obligated`, `Permitted`: deontic, on a specific act ("must / required"; "may / allowed"). The
  weaker "should / ought" is Obligated with `word` set to "should". A prohibition ("must not",
  "may not", "shall not", "forbidden to") is Permitted plus an O03 over the event: the denial of
  permission, never a negated obligation.
- The same surface word takes the operator of its sense: "must" is Must or Obligated, "may" is
  Might or Permitted, "can" is Can or Permitted, "could" is Can or Permitted together with Past
  (past narrative), or Might with no tense (speculation).
- "would": inside a that-complement it is Future on the complement event; "would not V" in a
  past narrative is an O03 over the event together with Past; any other "would" (an unrealized
  eventuality) has no template here: report the clause unmapped.
- Stack several O01 on one instance when the clause has several markings ("was cooking": Past
  and Ongoing).

- `t` (required): "O01"
- `on` (required; "@id" of a C01 / C14 / D01 / M01 / V01 / V02 / V05 instance): the predication
  marked.
- `head` (required; one of: Past, Future, Ongoing, Can, Might, Probably, Must, Obligated,

- `word` (optional; one of: should): "should" for the weaker should / ought obligation.

### O03 — Negation

When: An explicit "not", "n't", "never" or "no" denying a predication.

- `over` lists what is denied. For a verbal clause: its event. For a copular clause: its copular
  predication; when the predicate has several parts ("is not a legal dwelling") list ALL of them
  together, because the sentence denies the whole predicate and licenses neither half alone.
- Negation does not re-decide the subject. Parse every participant exactly as the positive
  sentence would: an indefinite or definite singular is a witness under negation just as without
  it. A generic denial needs the same surface signal a positive generic needs (a bare plural or
  an explicit quantifier): then the denial is an O03 over the R01 rule.
- A negated plural or group keeps both of its predications: list the group event AND its R03
  rule in `over`.
- "not … or" means neither: give one denied predication per alternative, each with its own O03.
  When instead at least one alternative is a denial ("Bob or Alice did not come"), report the
  clause unmapped with code G17.
- "not because X, but because Y": the event is NOT denied; give the L01 to X with `denied` true
  and the L01 to Y as usual.
- "no longer", "not anymore", "used to" (a state that held and has ceased), "not all / not
  every", "neither … nor" and "not yet / still not" have no template here: report them unmapped.
- A lexical antonym (unhappy, closed) is never negation.

### R03 — Distribution over a group

### L01 — Connective between two clauses

When: An explicit NON-temporal connective relating two clauses: causal (because, since, so, as a
result, therefore, consequently, thus), concessive (although, even though, despite) or
adversative (but, yet).

  though"). Never normalize it to another word.
- `main` is the main clause's event or state, `sub` the subordinate one. For a coordinating
  connective (so, but, therefore) the first clause is `main`. A fronted subordinate ("Because X,
  Y") still has Y as `main`.

- Negation inside a clause stays inside that clause (an O03 over that event); it never moves the
  link. Set `denied` true only for "not because X, but because Y", on the link to X.
- Only for an explicit connective: bare juxtaposition states no relation.
- A temporal connective (after, before, when, while, until, as soon as) is never an L01. A
  connective at the start of the text with no first clause is unmapped with code G06. A "but /
  except / unless" that introduces an exception to a generic, a purpose "to / in order to", and
  "if" have no template here: report them unmapped.

Slots:

- `t` (required): "L01"
- `connective` (required; a string): the surface connective, lowercase.
- `main` (required; "@id" of a V01 / V02 / V05 instance): the main clause's eventuality.
- `sub` (required; "@id" of a V01 / V02 / V05 instance): the subordinate clause's eventuality.
- `denied` (optional; true / false): true only for "not because X, but …".
