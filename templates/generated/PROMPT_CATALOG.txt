# Template parser — instruction set (generated from the catalog; never edited by hand)

catalog sha256 67b5023b362ac293 · 57 templates

You are a semantic parser. You read an English TEXT and describe what it states as TEMPLATE
INSTANCES: small JSON records, one per thing the text states, each an instance of one of the
templates defined below. You do NOT write logic atoms. A program renders your records into logic
deterministically: it builds the symbols, numbers the witnesses, sets the truth values, and
nests negation, tense and sealed content. Your job is recognition: which templates apply, and
what fills their slots.

Apply ONLY the templates in this document. They cover part of English on purpose. When a clause,
phrase or word contributes meaning that no template here covers, do not stretch a template to
fit it and do not drop it silently: report it under `unmapped` (see *Unmapped spans*) and still
parse everything else.

State only what the text states. World knowledge picks the reading; it never adds content. Every
instance and every slot value must be traceable to words in the TEXT: point at the words that
put it there; if you cannot, leave it out. No unstated class, property, possessor, location,
part-whole or causal link, however obvious.

A stated restriction, hedge or qualifier is never silently dropped, because omitting it widens
the claim. Carry it with a template, or leave the WHOLE claim out and report the whole clause as
unmapped. An unencodable qualifier never becomes an unqualified statement.

## Output

For each item write ONE JSON object and nothing else:

    {"id": "<the item id>",
     "instances": [ <instance>, ... ],
     "unmapped":  [ <unmapped span>, ... ],
     "issues":    [ <issue>, ... ]}

`instances` is a list of records `{"t": "<template id>", "id": "<label>", ...slots, "span":
"<words, verbatim>"}`. Give referents first, in order of first mention, then predications in
text order, then the scope operators (negation, modals, directives, sealed complements),
attachments (times, places, particles), rules and links. Every instance carries an `id` and a
`span` (see *Spans*). Use exactly the slot names defined for each template; omit an optional
slot that does not apply (never write null for it).

`issues` is a list (usually empty) of problems with THESE INSTRUCTIONS that the item exposed —
see *Reporting a problem with the instructions*. Parse the item as the instructions say in any
case; the report never changes the parse.

`unmapped` is a list (empty when everything is covered).

Strict JSON: double-quoted keys and strings, no comments, no trailing commas, no prose, no code
fences.

## Identifiers and fillers

- Every instance carries an `id`: a short lowercase label you choose, unique within the item.
  Suggested prefixes: `n` named individual, `x` witness, `g` group or portion, `e` event, `s`
  scope operator (negation, modal, norm, evidential), `c` copular predication, `l` location, `q`
  quantified range, `r` rule, `d` comparison or degree, `m` measure, `t` time, `k` link, `f`
  focus (n1, x1, e1, s1 …).
- A slot that points to another instance holds `"@<id>"`, for example `"Agent": "@n1"`.
- The id `now` is reserved for the text's REFERENCE TIME (the moment the text speaks from). You
  never write its instance; a deictic time (yesterday, tomorrow, last week) refers to it as its
  anchor, `"anchor": "@now"`, and the program supplies the instance, with calendar fields when
  the caller states the reference date.
- A slot that holds a CLAUSE — the content of a negation, a modal, a directive or an attitude,
  the complement of a control, causative, aspectual or psych verb, the content or the condition
  of a rule — holds a list of ids: the clause's predication, or the scope operator over it when
  it has one (`["@s1"]` for a negated or modalised clause); never the referents the clause
  mentions.
- A slot that holds a class, property, verb, scale or unit holds the bare LEMMA, for example
  `"class": "book"`.
- A participant slot holds either one: `"@x1"` for a specific referent, or a bare lemma for a
  non-specific or class-level filler ("pays tax", "cooked dinner" gives `"Patient": "dinner"`).
  Reserve the bare lemma for a non-specific filler; a specific definite or indefinite thing is
  always an instance.
- ONE instance per MENTION, and the identity stated. The first mention of a person, thing, group
  or event gets its instance as usual. Every LATER mention of the same referent — a pronoun or a
  demonstrative (a `mention` instance), a repeated name (a second `named-entity` instance), an
  anaphoric definite such as "a sluice … the sluice" (a second `witness` instance), a reflexive
  — gets its OWN instance, fills the slots of its own clause, and is linked to the referent's
  FIRST instance by a `coref` instance that says how sure the text makes the identity. Never
  fold a later mention into an earlier instance: the link is the resolution, stated where it can
  be checked and revised. An event anaphor ("That surprised everyone") is a `mention` linked to
  the event.
- The one pronoun that is NOT a mention: a pronoun bound by a range — "they" in "herons are
  patient if they are healthy", "it" in "every ferret sleeps when it is tired" — is the range
  itself, the arbitrary member. Fill the slot with the range's id (`"subject": "@q1"`); no
  mention instance and no coref, since there is no separate referent.
- A TEXT of several sentences is parsed together: a later sentence's mentions of earlier
  referents are new instances linked by `coref` to the first ones.
- A coordinated subject or object (Teodor and Yusra laughed; read the letter and the note) is
  one predication instance per conjunct, each with its own event, never a group. When the
  predicate holds only of the conjuncts together (met, argued, shared a thermos), no instance
  fits: report the clause as unmapped.

## Spans

- Every instance carries `span`: the words of the TEXT it is built from, copied verbatim — one
  string, or a list of strings when the words are not contiguous. Spans may overlap; together
  with the unmapped spans they should account for every content word of the TEXT.
- What a span covers. A REFERENT: its phrase as written — the name (`"Lamine"`), the noun phrase
  with its determiner or possessor (`"the envelope"`, `"Yusra's quilt"`), the pronoun (`"she"`),
  the quantified phrase (`"All alloys"`). A PREDICATION: the stretch from the first to the last
  word of its verb and its own arguments as written (`"Ottoline took the envelope from Lamine"`,
  `"Yusra laughed"`); words of an operator or attachment that fall inside that stretch are
  included (`"Teodor read only the letter"`), those outside it are not (`"Lamine cut the loaf"`
  beside the adjunct `"with a knife"`). An EMBEDDED clause: the clause's own words only
  (`"Lamine lent Ottoline the trowel"` under *believes that*, `"to sing"` under *began*,
  `"Teodor laugh"` under *made*). A SCOPE OPERATOR, FOCUS or LINK: the word or words that signal
  it (`"did not"`, `"Don't"`, `"might"`, `"Only"`, `"because"`, `"in order to"`; `["It was",
  "who"]` for a cleft); an imperative with no marker word spans its clause. An ATTACHMENT: its
  phrase with its preposition (`"with a knife"`, `"in the barn"`, `"on Monday"`, `"loudly"`,
  `"with care"`, `"about ferrets"`); a time relation whose reference is a clause spans its
  connective alone (`"after"`, `"while"`), the clause having its own span. A COREF: the two
  mentions' words as a list (`["Lamine", "she"]`). A RULE (a generalization, a conditional
  property, a distribution) or a class statement: the whole clause it generalizes (`"Clay is
  soft when wet"`).
- A span is provenance, not meaning: it says which words licensed the instance, so that every
  fact can be traced to the TEXT and checked. It never changes what the instance states.

## Lemmas and symbols

- Lemmatize every class, property and verb to its dictionary base form: verbs to the base (ran,
  running → run), nouns to the singular (ravens, mice → raven, mouse), adjectives to the base
  (taller → tall). All lemmas are lowercase snake_case.
- Inflection only, never derivation: a word derived into another part of speech is a different
  word and keeps its own form (`coastal` is not `coast`, `tidal` is not `tide`). A participle
  used as a modifier is an adjective, not the verb ("a laminated worktop" has the property
  `laminated`); the same participle in "the worktop was laminated" is a verb. Decide by the
  word's function here, not its shape. A manner adverb in -ly keeps its surface form
  (`brightly`, never `bright`).
- A phrasal or particle verb is ONE symbol joining the lemmatized verb and its particle
  (`go_out`, `break_down`, `bring_in`, `switch_on`). Never swap in a single-word synonym, never
  split off or drop the particle.
- A fixed multi-word idiom is one surface symbol keeping every word (`spill_the_beans`), used
  only when the literal reading is incoherent for these participants; take the literal reading
  whenever it is available.
- Names: you give the surface string; the program derives the symbol.

## Choosing a template

A template fires only where its construction is present. If a clause looks like a template's
construction but a boundary case of that template says it is not, do not use it: use the
template that covers it when one is listed here, otherwise report the span under `unmapped`.
Never pick the nearest template.

## Unmapped spans

An unmapped span is a record:

    {"span": "<the words, verbatim>", "code": "<code>", "construction": "<one sentence naming the construction>"}

Use it for every clause, phrase or word whose contribution no template here covers. `span` is
copied verbatim from the TEXT. `construction` names the grammatical construction in one plain
sentence (what it is, not how you would encode it). Use the most specific code that applies,
otherwise G00.

Decide what to keep by ENTAILMENT. When the sentence still entails the rest without the unmapped
part, keep the instances the templates license and report just that part: an added time, date
bound, duration, place, manner, amount or tag leaves the event itself true ("was demolished
before 1960" still says it was demolished). When the rest would NOT follow without the unmapped
part, leave the whole claim out and report the whole clause: a negated condition ("unless it
rains, Lamine sings"), a hedge ("supposedly full"), an unencodable quantity ("too much salt").

Referents inside an unmapped span: a NAME still gets its instance (a name is rigid, the same
individual wherever it appears in the text), but a common-noun phrase or a pronoun does not. A
witness is introduced only by a clause a template covers; the span carries the noun verbatim,
and if a covered clause mentions the same thing, that clause's instance is the referent. Never
introduce a witness for something stated only in words you report as unmapped.

Codes:

- G00: anything no template here covers and no other code names
- G01: a comparative with no stated standard ('a sturdier bracket', 'prices ended lower')
- G02: an adverb with no slot: sequence (initially, eventually, finally), scope or domain
  (nationally, locally), a degree word on a manner adverb, on a class-level statement or on an
  adjective with a complement (laughed very loudly; ferrets are very curious; very fond of
  Teodor)
- G03: a post-nominal tag on a name (a party or district tag, a ticker, a bracketed code)
- G04: an irrealis relative clause or a lone would-have consequent ('the bridge that would have
  collapsed')
- G05: a connective at the start of the text with no first clause to relate ('But the vote
  stood.')
- G06: a result or outcome infinitive ('woke to find the door open')
- G07: 'only one N' — a focus particle on a bare count
- G08: an 'unless' or 'if not' conditional
- G09: stay / remain / keep with a locative continuation ('stayed in the hall')
- G10: the verbatim wording of a quotation (its content is parsed; the wording itself is not
  kept)

## Reporting a problem with the instructions

If, while parsing an item, an instruction in this document seems contradictory, ambiguous, or
missing for what the item needs, or two templates both seem to apply to one span, do not resolve
it by guessing silently: parse as the instructions say (for an overlap, use the template whose
construction fits the span best) and add an issue record:

    {"code": "<P00 | P01>", "where": "<section title or template id>", "text": "<one sentence>"}

Codes: P00 — an instruction is contradictory, ambiguous or missing for this item; P01 — two
templates both seem to apply to one span (name both in `text`). An issue is a report about the
instructions, never about the text: a construction the templates do not cover is an unmapped
span, not an issue.

## Templates

## Referents — the things the text talks about

### group — A plural noun phrase introducing a group of individuals

When: A plural noun phrase headed by a common noun — the ferrets, several students, three
ladders, a few children, dozens of protesters, a lot of rocks, both ladders, Yusra's ferrets —
introducing a group of individuals of that class. The group gets one witness symbol. Its size is
recorded as an exact count when a numeral or "both" states it (three → 3, both → 2) and as the
vague phrase as written otherwise (several, a few, dozens). A definite group ("the", "these",
"those", "both") is marked definite; a possessed group (Yusra's ferrets) records its possessor
and needs no definite mark — the possessor presupposes it.

Forms:
- the <N>s
- <numeral> <N>s
- several / a few / many / dozens of / a lot of <N>s
- both <N>s
- <possessor>'s <N>s

Not this template:
- coordinated names or referents — Teodor and Yusra, the ladder and the quilt: one instance per
  conjunct, no group
- a bare plural read generically — ferrets are curious: a statement about the class
- a quantifier word — all ferrets, every ferret, each ferret, most ferrets, no ferret: a
  quantified generalization, not a group
- a quantified portion of a definite group — two of the ferrets, most of the ferrets, the rest
  of the ferrets: a portion, with this group as its whole; all of / each of / both of the
  ferrets: this group itself, with a distribution; none of the ferrets: a range
- a singular noun phrase — the ferret, a ladder: a witness

Slots:

- `t` (required): "group"
- `id` (required; your label for this instance): your label for the group.
- `class` (required; a lemma): the head noun's lemma, singular (ferret).
- `definite` (optional; true / false): true for the / these / those / both; absent for a
  possessed group (the possessor presupposes it) and otherwise.
- `count` (optional; a number): the exact size when a numeral or both states it (three → 3; both
  → 2).
- `quantity` (optional; a string): the vague size phrase as written (several, a few, some, many,
  dozens, a lot, lots, plenty); absent when a numeral or both states the size.
- `props` (optional; a list of lemmas): adjectival properties stated in the phrase.
- `possessor` (optional; "@id" of a referent instance, or a bare lemma for a non-specific
  filler): the possessor of a possessive phrase (Yusra's ferrets).

Example (a vague size; the sleeping distributes to each ferret). TEXT: Several ferrets slept.

### mention — A pronoun or a demonstrative standing for an earlier referent

When: A pronoun or a demonstrative used as a noun phrase that stands for something already in
the text: he, she, it, they, him, her, them, his, its, their, himself, herself, themselves,
this, that ("that surprised Yusra"). One instance per occurrence; the word is recorded. The
mention fills the slot a name or a witness would fill (the actor, the patient, the possessor of
a witness), and a coref instance links it to the referent's first instance. A repeated name
(Yusra … Yusra) is a second named-entity instance, and an anaphoric definite (a sluice … the
sluice) a second witness, each with its own coref instance: they are not mentions.

Forms:
- <pronoun>
- <possessive pronoun> <N>
- <demonstrative> as a noun phrase

Not this template:
- a relative pronoun opening a relative clause — the clerk who laughed, the quilt that Yusra
  sold: a different construction, reported as unmapped
- an expletive — it rained, it is clear that: no referent, no mention
- a generic or impersonal pronoun — one never knows, you cannot be sure, they say: no referent,
  reported as unmapped
- a pronoun whose antecedent is not in the text (a text beginning "He laughed."): still a
  mention, but with no coref instance to state

Slots:

- `t` (required): "mention"
- `id` (required; your label for this instance): your label for the mention (m1, m2 …).
- `word` (required; a string): the pronoun or demonstrative as written, lowercase (he, her, it,
  that).

### named-entity — A proper name introducing a rigid referent

When: A proper name (a person, a place, an organisation, a product) used to refer to one
individual. A name is rigid: it is never introduced inside a scope. Its symbol is the name with
a number for this text (sk_teodor_1); whether two texts' Teodors are one person is a separate,
revisable link, not a matter of spelling.

Forms:
- <Name>
- <Title> <Name>

Not this template:
- a common noun with an article — the clerk, a thermos: a witness, not a name
- a bare mass or domain noun — rust, chemistry: a constant, not a name

Slots:

- `t` (required): "named-entity"
- `id` (required; your label for this instance).
- `name` (required; a string): the surface name, capitalised as written.
- `title` (optional; a string): a leading title, if any.
- `class` (optional; a lemma): the class an appositive or a title phrase states for the name
  (Lamine, a glazier); a predicative is a N is a copular instance, not this slot.

Example. TEXT: Teodor

Instances:

    [
      {"t": "named-entity", "id": "n1", "name": "Teodor", "span": "Teodor"}
    ]

The program renders these instances as:

    (Name sk_teodor_1 "Teodor")

### portion — A quantified portion of a definite whole

When: A noun phrase of the form "<quantity> of <the whole>" where the whole is a SPECIFIC
referent the text presupposes — a definite or possessed group (the ferrets, these quilts,
Yusra's ferrets, them) or a definite singular whole (the loaf, the budget, the field, the
morning) — and the quantity is a NUMBER of two or more (two of the ferrets, twenty of the
students), a VAGUE COUNT (several of, a few of, dozens of), a PROPORTION WORD (most of, some of,
many of, few of, half of), a FRACTION or a PERCENTAGE (a third of, two-thirds of, forty percent
of, 12.5% of, three out of five of), or "the rest of". Write the whole's own instance first (the
group or the witness; a pronoun is a mention), then one portion instance naming it: `members` is
the members' class when the whole is a group (ferret), absent for a mass or a single thing;
exactly one of `count`, `quantity`, `word`, `numerator` (with `denominator`) or `rest` says how
much. Number words are converted (two → 2, forty percent → 40 over 100, a third → 1 over 3; half
stays the word half). The portion then fills the clause's slot like any referent, and a
distribution instance over it says the predicate holds of each member when it does (most of the
quilts are damp: each is).

Forms:
- <n> of the <N>s
- several / a few / dozens of the <N>s
- most / some / many / few / half of the <N>s
- half / most / the rest of the <N>
- a third / two-thirds / forty percent / 12.5% of the <N>(s)
- <quantity> of them / of Yusra's <N>s

Not this template:
- one of the Ns — one of the weavers, one of the seven sins: a single member, a witness of the
  class linked to the group by a part-whole instance (word one of), not a portion
- all / each / both / every one of the Ns — all of the ferrets slept: the whole group itself
  (both: count 2), with a distribution; none of the Ns — none of the ferrets slept: a range with
  the quantifier none, and the generic builds the rule
- a quantifier on a bare class noun — most students, three ferrets, half the time: no whole is
  stated; most students is a range of a generalization, three ferrets a group; a bare "most" is
  never a portion
- a quantity of a substance — a cup of tea, three metres of cloth, a lot of water: a witness of
  the stuff with a measure or a vague quantity phrase on it (the measure and witness templates),
  not a portion of a whole
- a plain part named by a noun — a piece of the loaf, the top of the ladder, a member of the
  guild: a witness and a part-whole instance; the amount is not stated
- one of the ADJ-est Ns — one of the oldest glaziers: a superlative
- a possessive of-phrase — the quilt of Yusra, a friend of Lamine: a witness with its possessor,
  or a stative relation
- a percentage as a value, not a share of a whole — unemployment is 5 percent, fell by 8
  percent: a measure with the unit percent

Slots:

- `t` (required): "portion"
- `id` (required; your label for this instance): your label for the portion (g2, g3 …).
- `whole` (required; "@id" of a referent instance, or a bare lemma for a non-specific filler):
  the whole the portion is taken from: the id of its instance — a definite or possessed group
  (the ferrets, Yusra's ferrets), a definite witness (the loaf, the budget) or a mention (them).
- `members` (optional; a lemma): the class of the portion's members when the whole is a group,
  lemmatized to the singular (ferret); for a pronoun whole, its antecedent's class when the text
  names it; absent for a mass or a single whole (half of the loaf).
- `count` (optional; a number): an exact number of members, two or more (two of → 2, twenty of →
  20); number words converted.
- `quantity` (optional; a string): a vague count phrase as written (several, a few, a couple,
  dozens, a handful, a number).
- `word` (optional; a lemma): a proportion word as written, lowercase (most, some, many, few,
  half).
- `numerator` (optional; a number): the numerator of a stated fraction or percentage (two-thirds
  → 2, a third → 1, forty percent → 40, 12.5% → 12.5, three out of five → 3); always with
  denominator.
- `denominator` (optional; a number): the denominator (two-thirds → 3, a third → 3, a percentage
  → 100, three out of five → 5); always with numerator.
- `rest` (optional; true / false): true for the rest of / the remainder of; absent otherwise.
- Exactly one of `count`, `quantity`, `word`, `numerator`, `rest` is filled.

### range — The quantified variable of a verbal generalization

When: The subject or object of a verbal generalization over a class: a quantifier word with a
class noun (every ferret, each student, all ferrets, most students, many herons, few ferrets, no
ferret, none of the ferrets) or a bare plural read generically (ferrets sleep). It stands for an
arbitrary member of the class, not for a particular individual or a particular group. One range

ranges over the class occasion; the frequency template builds that rule.

- most / many / few <N>s
- no <N> / none of the <N>s
- <N>s V …
- every <unit / day part / weekday>; on <weekday>s; daily
- <adverb of frequency>

- a specific group — the ferrets, several ferrets, three students, some students: a group
  referent, and what is said of its members is a distribution

- `quantifier` (optional; a string): the quantifier word as written (every, each, all, most,

### change-of-state — A change of state, by itself or brought about

### norm — A stated obligation, permission, prohibition or exemption

When: A clause whose deontic status is stated: an OBLIGATION — must, has to, needs to, shall, is
required / obliged to, is to; weaker, should, ought to, is supposed to, had better — a
PERMISSION — may, can, could, is allowed / permitted / free to — a PROHIBITION — must not, may
not, cannot, shall not, is not allowed to, is forbidden to, is prohibited / banned from — or an
EXEMPTION — need not, does not have to, is not required to, is exempt from. The clause under the
norm is parsed with its own template: its actor the subject, or empty for a passive (the ledger
must be signed) and for a gerund with no subject (smoking is forbidden); its tense present for a
bare infinitive (must send), past with aspect perfect for a perfect infinitive (should have
sent); an indefinite object inside the act (wear a badge, send a letter) is a witness, as
anywhere — it exists only inside the seal, and on a class it is a function of the member — while
a bare plural or mass object (wear gloves, carry water) is a bare lemma. Then write the norm
instance over it, with `kind` for the concept, `word` for the words as written and `weak: true`
for should, ought to, supposed to, had better. Negation is never a separate instance: must not,
may not, cannot, is not allowed to are a prohibition; need not, does not have to, is not
required to are an exemption; should not is a weak prohibition. A deontic adjective or
participle with "be" — forbidden, prohibited, banned, illegal, unlawful; allowed, permitted,
permissible, legal; mandatory, compulsory, obligatory, required; optional, voluntary — is the
same instance over the action its subject names: a gerund or an action noun (parking in the
street is not allowed: the activity park with its location; payment is required: a transfer pay
with no parties; it is forbidden to smoke: the activity smoke). The norm's own `tense` is past
for had to, was allowed / required / forbidden to and could as a past permission, future for
will have to; absent otherwise. On a class — glaziers must wear gloves, visitors may not enter

### time — The time at which an event takes place

When: A time expression saying when the clause's event takes place: a calendar date or any part
of one (in 2019, in May, on 3 May 2019, on Monday), a clock time (at 3 pm, at 2:30 pm, at noon,
at midnight), a deictic relative to the moment the text speaks from (now, today, tonight,
yesterday, tomorrow, last / this / next week, month or year), a time named by a word (at dawn,
at night, in autumn, later, this morning), a measured distance from an anchor (three days ago, a
year ago, in two weeks, two days after the audit, a week later), or an anaphoric phrase naming a
time by one the text stated before it (that evening, the same day, the next day, the following
morning, the week after). The event is parsed with its own template; the time instance names
that event and describes the time: a date or a clock time by its fields (year, month, day,
weekday, hour, minute), a deictic by the `deictic` word with the reference time as its anchor, a
measured distance by its `offset`, `unit` and `direction` from its anchor (the reference time
for ago / from now / in n units; a stated event or time for before / after it and for later /
earlier), an anaphoric phrase likewise from the antecedent event or time (offset 0 for that /
the same, 1 for next / following / after, a day part as a second instance), a named time by its
name. One instance per time expression; a day part beside a date or an offset (Monday morning,
the following morning) is a second instance. A time no clause places an event at — the reference
of a time relation (before noon), the edge of a window (within three days) — is an instance with
no event. When the time is predicated of an event noun by "be" (the meeting is at noon, the
audit was on Monday), the noun is a witness marked eventive, the time attaches to it, and this
instance records the clause's tense.

Forms:

- <clause> at <clock time>
- <clause> <deictic>

### time-relation — When an event takes place relative to another event or a time

When: A temporal preposition or connective that places the clause's event relative to a
reference: before, after, during, while, when, until, since, by, from … to. The reference is
another event — a clause of its own (after Lamine sang, while Yusra waited), parsed with its own
template, or an event noun (after the audit, during the meeting), a witness marked eventive — or
a time: a date, a clock time or a named time (before noon, since 2019, until dawn), a time
instance with no event of its own. The clause's event is parsed with its own template; the
relation instance names that event, the reference and the relation as read, and keeps the word.
One instance per temporal phrase or connective; "from 2015 to 2019" is two, a start and an end.
When the relation is predicated of an event noun by "be" (the audit was before the meeting), the
noun is a witness marked eventive, the relation attaches to it, and the instance records the
clause's tense. A gerund clause after a temporal preposition (after leaving the barn, before
eating) is a clause of its own: parse it with its verb's template, its actor the main clause's
subject unless the phrase states one (after Yusra's leaving), its tense the main clause's, and
name its event as the reference. A window — within three days, in the past six months, in the
last two years — is a bound on a time at an offset: a time instance with no event, offset from
its anchor (three days after now; six months before now), and the relation TimeAtMost (within)
or TimeAtLeast (in the past / last) on it. The span is the connective alone when the reference
is a clause (the clause's words have their own span), the whole phrase when the reference is a
noun phrase or a time (after the audit, until dawn, by Monday, within three days).

Forms:
- <clause> before / after / until / since / by / during <event noun or time>
- <clause> before / after / while / when / until / since / once / as soon as <clause>
- Before / After / While / When / Until / Once <clause>, <clause>
- <clause>, then <clause>
- <clause> from <time> to / until <time>
- <event noun> is / was before / after / during <event noun or time>
- <clause> after / before / while / since / until <V-ing …>
- <clause> within <n> <units>
- <clause> in the past / last <n> <units>

Not this template:
- a measured distance — three days ago, in two weeks, two days after the audit, a week later: a
  time point at an offset from its anchor; a time
- a time the event takes place at — in 2019, on Monday, at noon, yesterday, at dawn: a time, not
  a relation
- a duration — for six hours, lasted two days: the measure template, with no slot here; the
  phrase as unmapped
- a frequency or a schedule — every day, twice a week, often: a frequency
- a causal since or as — Yusra left, since the gate was open: a reason, a link; a temporal since
  or as is this template
- every time or whenever with a clause — whenever the bell rings: a generalization over the
  when-clause's events, the frequency template; not a relation between two particular events
- a main clause with no event of its own — the ladder was crooked until Monday, Yusra was in the

## Rules — generic and quantified statements

### conditional — An indicative conditional

When: "If P, Q" and its kin — if … then, provided that, as long as, in case, even if — and a
stative when-clause (the ladder is brittle when cold; Teodor is grumpy when tired). Parse the
condition with its own template (a predication for an event — Lamine sings; a copular instance
for a state — cold, open, tired, with the subject it is said of) and the consequence with its
own (a predication, or a negation, modal or norm over it, or a copular instance for a state),
and name them in `condition` and `over`. With an eventive condition the rule ranges over the
condition's events, and the consequence's event is a function of each; with a stative condition
the rule holds between the states as stated. When the subject is a class — herons are patient if
the weather is sunny — it is a range instance listed in `ranges`, the consequence a copular
instance over it, and `generic: true` marks a bare plural (no quantifier word). The mood is
indicative: the clauses are real possibilities; a subjunctive (if Lamine had sung, Yusra would
have left; if Yusra sang, Teodor would leave) is a counterfactual. The span is the whole
sentence.

Forms:
- If <P>, <Q> / <Q> if <P>
- <X> is ADJ when / if ADJ
- <class>s are ADJ if <P>
- Provided that / as long as / in case <P>, <Q>

Not this template:
- a counterfactual or a hypothetical with would — if Lamine had sung, Yusra would have left; if
  Yusra sang, Teodor would leave: the counterfactual template
- unless, or if not — unless it rains, Lamine sings; if Yusra does not sing, Lamine leaves: a
  negated condition, with no form yet; report the clause as unmapped (G08)
- an eventive when-clause — when Lamine sings, Yusra leaves; whenever the bell rang: a
  generalization over the when-clause's events, the frequency template
- a class's property under a state of its members — clay is soft when wet, all alloys are
  brittle when cold: the conditional-property template; here the subject is an individual, or
  the condition is about something else than the member
- a causal connective — because, since, so: a link between two asserted clauses, not a condition
- "if" introducing an embedded question — asked if Yusra had left: a sealed question under the
  verb, not a condition
- a purpose or a result infinitive — left to sleep, woke to find the door open: not a condition

Slots:

- `t` (required): "conditional"
- `id` (required; your label for this instance): your label for the rule (r1, r2 …).
- `condition` (required; a list of "@id" of the instances that state the clause): the if-clause:

### frequency — How often an event recurs

When: An expression saying how often the clause's event recurs. Two forms. (1) A QUANTIFICATION
OVER OCCASIONS: a period of one unit — every day, each morning, every Monday, on Sundays, every
night, daily, weekly, monthly, yearly, annually, nightly — a rate — twice a week, three times a
day, once a year, twice per month — or a frequency adverb — always, usually, normally,
generally, often, frequently, regularly, sometimes, occasionally, seldom, rarely, hardly ever,
from time to time. The occasion is a range instance over the class of occasions (day, week,
month, year; morning, night; sunday, monday; and `occasion` for an adverb with no stated
period), the clause is parsed with its own template, and this instance names the range in
`occasion` and the predication in `over`, with `every: 1` for a period, `times` for a rate (the
count in each occasion: twice a week → 2 with a range over week) or `level` for the adverb; a
generic subject or object (ferrets often bite, every ferret sleeps every night) is a range
listed in `ranges`, and no generic instance is written. Two cases take their restrictor from the
sentence instead of an occasion range. (1b) An ADVERB ON A CLAUSE WITH AN ATTACHMENT — Teodor
always arrives at noon, Yusra usually swims in the lake, Lamine often sings loudly: the rule
ranges over the clause's own events and asserts the attachment of them; name the predication in
`restrictor` (no `occasion`, no `over`) and leave its time, place or manner attached to it as
usual; "never" here is the same rule at strength 0 (Teodor never arrives late). (1c) A WHEN /
WHENEVER / EVERY TIME CLAUSE — when Lamine sings, Yusra usually leaves; whenever the bell rang,
the ferret hid: the when-clause's predication is the restrictor, named in `restrictor`, and the
main clause's predication is named in `over`; `every: 1` for whenever / every time / each time,
`level` for an adverb in the main clause, and `every: 1` again for a bare "when" clause read as
a generalization. (2) A PATTERN RECORDED ON THE EVENT: a period of more than one unit (every two
weeks, every other day, every three years) or a bare count of occurrences (once, twice, three
times): the clause's predication is named in `event` with `every` and `unit`, or with `times`.

day) is an attachment on the event as always, rendered inside the rule.

## Links — connectives between clauses

### coref — A later mention stands for an earlier referent

When: The judgement that a later mention stands for a referent introduced earlier in the text: a
pronoun (he, it, her), a repeated name (Yusra … Yusra), an anaphoric definite (a sluice … the

later mention, the referent's FIRST instance in the text, and the certainty: certain when only
one antecedent fits, likely when one fits clearly better than another, unsure when the text

mention; for an open choice between two candidates, one instance per candidate.

Forms:
- <N> … <pronoun>
- <Name> … <Name>
- a <N> … the <N>
- <clause>. That <V> …

### focus — A focus particle or a cleft on a clause

When: A focus particle on a constituent of a verbal clause — only, just, solely, alone
(exclusive); even (scalar); also, too, as well (additive), with either and neither as their
forms under negation — or an it-cleft (it was Lamine who washed the quilt) or a pseudo-cleft
(what Teodor read was the letter). The clause is parsed with its own template as if the particle
were absent; the focus instance names the head, the focused constituent — the referent id of the
subject or object the particle sits on, or the verb's lemma for a focus on the verb phrase
(Teodor only slept → sleep) — and the clause's event. A clause-final too / as well / either
focuses the subject unless the text says otherwise. One instance per particle or cleft.

Forms:
- only / even / also <subject> V …
- <subject> V only <object>
- <subject> only / even V
- <subject> V … too / as well / either
- it was <X> who / that <clause>
- what <clause> was <X>

Not this template:
- a particle on a count — only one ferret, only three letters: no carrier for the exclusivity on
  a number; report the particle under G07
- a particle on a copular or a class statement — only the ladder is crooked, herons are also
  common: the clause has no event for the atom to name; keep the predication and report the
  particle as unmapped
- a particle on a generalization — only ferrets sleep in burrows: the event is a rule's
  variable, no top-level atom can name it; report the clause as unmapped
- "even though", "even if" — a connective or a conditional, not a scalar particle
- "just" meaning recently — has just arrived: a time adverb with no slot (G02); "alone" meaning
  without company — slept alone: a manner
- "also" or "too" opening a sentence as a discourse connective — Also, Teodor left: a connective
  with no clause to relate here (G05)
- a negated cleft — it was not Lamine who washed the quilt: the backgrounded clause would need
  an actorless predication; report the clause as unmapped
- "the only N" — the only locksmith: an adjective inside the noun phrase, not a particle; report
  it as unmapped

Slots:

- `t` (required): "focus"
- `id` (required; your label for this instance): your label for the focus (f1, f2 …).
- `head` (required; one of: Only, Even, Also, Cleft): Only for only / just / solely / alone;
  Even for even; Also for also / too / as well / either / neither; Cleft for an it-cleft or a
  pseudo-cleft.
- `filler` (required; "@id" of a referent instance, or a bare lemma for a non-specific filler):

- `event` (required; "@id" of a predication instance (the clause's event)): the clause's event:

- `surface` (optional; a string): the particle as written (only, just, solely, alone, even,

### link — A stated relation between two clauses

When: Two clauses joined by a connective that states why, in spite of what, or in contrast to
what: because, since (causal), so, therefore, thus, consequently, as a result, although, even
though, despite (with a clause), but, yet. Each clause is parsed with its own template; the link
instance names the two event instances — the predication instances themselves, even when a
clause is negated or under a modal (the negation or modal instance stays over the clause; the
link points at the event) — and the connective. The main clause comes first: for "X because /
since / although / even though Y", X is the main clause whether it comes first or after a
fronted Y; for "X, so / but / yet / therefore Y" and for a connective opening the next sentence
("… . Therefore Y."), the first clause is the main one and the connective's clause the second.
One instance per connective.

Forms:
- <X> because / since / although / even though <Y>
- Because / Although <Y>, <X>
- <X>, so / but / yet <Y>
- <X>. Therefore / As a result / Consequently, <Y>.

Not this template:
- a temporal connective — after, before, when, while, until, once, as soon as, then, since (a
  time): a time relation, not a reason or a contrast
- a connective with a noun phrase, not a clause — despite the storm: an oblique (Despite) on the
  event; because of the rain, due to the audit: no head; report the phrase as unmapped
- a connective opening the text with nothing before it — "But Lamine left.": no first clause to
  relate; parse the clause and report the connective (G05)
- a clause with no event of its own as an endpoint — the ladder is crooked because it is old,
  Yusra left because the gate was open: a copular, locative or degree clause has no event symbol
  to link; both clauses are parsed and the connective reported as unmapped
- a conditional — if Lamine sings, Yusra leaves: the conditional template; a subjunctive (if
  Lamine had sung, …): the counterfactual template; unless / if not: still unmapped (G08)
- an exception to a generalization — ferrets sleep, but this one works: the but introduces a
  defeasible exception, a different construction; report the clause as unmapped
- a purpose — went to the market to buy a thermos, in order to sleep: a purpose link
- so that with a clause — left so that Yusra could sleep: a purpose with a finite clause; no
  head here; report it as unmapped
- a bare sequence of clauses or sentences with no connective — Lamine sang. Yusra left.: no
  relation is stated; no link

Slots:

- `t` (required): "link"
- `id` (required; your label for this instance): your label for the link (k1, k2 …).
- `head` (required; one of: Because, Since, So, Therefore, Thus, Consequently, AsAResult,
  Although, EvenThough, Despite, But, Yet): the connective as written, one word in CamelCase: as
  a result → AsAResult, even though → EvenThough; since only in its causal sense.
- `main` (required; "@id" of a predication instance (the clause's event)): the main clause's
  event: the id of its PREDICATION instance (an activity, a motion, an attitude …) — never the
  id of a negation or modal instance over it, even when the clause is negated — the clause the
  connective's clause attaches to (X in 'X because Y', even when Y is fronted), or the first
  clause for so / but / yet / therefore.
- `sub` (required; "@id" of a predication instance (the clause's event)): the connective's own
  clause's event: the id of its predication instance (never of a negation or modal over it): Y
  in 'X because Y', the second clause for so / but / yet / therefore.

### purpose — An action's stated aim

When: A clause with a purpose infinitive — to V, in order to V, so as to V — stating the aim of
the clause's action: went to the market to buy a thermos, worked to buy a spindle, sang in order
to please Teodor, left so as to sleep. Parse the action with its own template; parse the aim
with the template its verb takes, its actor the action's subject and its tense present; then
write the purpose instance naming the action, the aim and the connective. A fronted purpose (In
order to sleep, the ferret left the barn) is the same. The purpose follows its action into a
negation or a modal over the clause: never list it in their `over`.

Forms:
- <action> to <V2> …
- <action> in order to / so as to <V2> …
- In order to <V2> …, <action>

Not this template:
- the complement of a control, attitude or causative verb — tried to sleep, wants to leave, got

- a result or outcome infinitive — woke to find the gate open, rebounded to close at par: no aim

- the consequence of too or enough — too tired to sing, tall enough to reach the shelf: a degree

- so that with a finite clause — left so that Yusra could sleep: a purpose with its own subject
  and modal; no head here; report it as unmapped
